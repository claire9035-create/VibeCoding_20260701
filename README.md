## Dog API Practice

### What I Learned
- Used Dog API to get random dog images.
- Used `fetch()` to send an API request.
- Used `.json()` to read the API response.
- Used `data.message` to get the image URL.
- Used a dropdown menu to select different dog breeds.
- Used Chrome DevTools Console to inspect API data.
- Used Chrome DevTools Network to inspect Request and Response.

### API Flow

User selects a dog breed  
→ Clicks the button  
→ `fetch()` sends a Request  
→ Dog API returns JSON data  
→ JavaScript reads `data.message`  
→ The image URL is assigned to `<img>`  
→ The dog image appears on the webpage
